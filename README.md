# Flood Radar Backend

Backend-focused flood alert system built with Node.js, TypeScript, PostgreSQL, Prisma, and REST APIs.

## Current Status

This project is currently in development. The main focus is backend architecture, authentication, database modeling, and external weather API integrations.

## Tech Stack

- Node.js
- TypeScript
- PostgreSQL
- Prisma
- Docker
- REST APIs
- Git

## Main Features

- User authentication
- Database modeling with Prisma
- Weather/flood-risk data structure
- API endpoints for alert-related data
- Backend architecture for a future flood monitoring platform
